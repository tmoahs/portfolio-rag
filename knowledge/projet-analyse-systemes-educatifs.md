# Analyse de données de systèmes éducatifs

## Contexte

Le projet d'analyse de données de systèmes éducatifs est un projet de fondation, centré sur l'analyse exploratoire de données (EDA) de systèmes éducatifs mondiaux. Il m'a permis de me familiariser avec l'environnement de travail standard des data scientists, le notebook Jupyter, et de maîtriser les premières étapes de toute analyse : la manipulation de données et l'exploration univariée. Je l'ai réalisé dans le cadre de ma formation de Data Scientist OpenClassrooms, en 2025.

## Ce que j'ai fait (mon rôle personnel)

J'ai pris en main le notebook Jupyter pour structurer et commenter mon analyse. J'ai manipulé les données avec la librairie Pandas, un outil essentiel pour traiter des jeux de données. J'ai mené une analyse exploratoire univariée pour comprendre la distribution et les caractéristiques de chaque variable. J'ai créé des représentations graphiques pour visualiser et communiquer les premières conclusions. L'analyse a abouti à la construction d'un score composite pour évaluer et classer les pays selon leurs performances éducatives.

## Technologies utilisées

J'ai utilisé Python, Pandas, Matplotlib, Seaborn et Jupyter Notebook.

## Résultats

L'analyse a produit une EDA complète des données de systèmes éducatifs mondiaux, avec un nettoyage et une manipulation des données. Elle a abouti à un score composite permettant de classer les pays selon leurs performances éducatives. Le code est disponible sur github.com/tmoahs/Analyse-Donnees-Systemes-Educatifs.

## Ce que j'en ai appris

Ce projet m'a fait poser les bases d'une analyse de données structurée, à travers l'analyse exploratoire (EDA). J'y ai appris à utiliser les opérations fondamentales de Python et Pandas pour préparer les données. J'ai aussi travaillé la communication d'informations par des graphiques, et la maîtrise de Jupyter Notebook, un standard dans l'industrie de la data.
